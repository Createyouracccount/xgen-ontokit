# L02 — 루프 탈출 판정 (2026-10-09)

**결론: L00 §3 탈출 조건을 EVAL·HOLDOUT 양쪽에서 충족. 루프 종료.**
검증된 주장의 범위는 §4 에 한정한다.

## 1. 무엇이 검증됐나

> 벡터 검색(제품 API 상위 40청크)에 **LLM-free ontokit 그래프의 질의 결과를 병합**(판독기 답 ∪ 그래프 결과, 개수는 그래프)하면,
> 같은 로컬 판독기(Qwen3-8B)의 **실제 답**이 열거·관계·다중 홉 질문에서 벡터만 쓸 때보다 좋아진다 —
> 개발에 쓰지 않은 처음 보는 문서 3,000건에서도.

## 2. 판정표 (판독기 MLX Qwen3-8B-4bit, 구조형 180문항, 쌍 부트스트랩 95% CI)

| 조건(L00 §3) | EVAL (wiki2) | HOLDOUT-1 (사용 2/3) |
|---|---|---|
| ① MRG:ontokit_r5 − VLLM ≥ +0.05, CI 하한 > 0 | **+0.081 [+0.049, +0.115]** ✅ | **+0.057 [+0.030, +0.086]** ✅ |
| ② 조회(L) Δ ≥ −0.03 | −0.024 [−0.076, +0.012] ✅ | −0.007 [−0.096, +0.063] ✅ |
| ③ 재현(temperature 0) | 결정적 | 같은 문항 VLLM 68/68 동일 ✅ |
| ④ 양성 대조 MRG:oracle − VLLM (68) | +0.699 [+0.599, +0.792] ✅ | +0.630 [+0.521, +0.736] ✅ |
| ④ 음성 대조 MRG:placebo2 − VLLM (68) | +0.023 [−0.024, +0.083] ✅ | +0.009 [−0.021, +0.048] ✅ |

형태별(HOLDOUT): VLLM → MRG:ontokit_r5 — E1 0.048→0.173 · E2 0.000→0.063 · R 0.084→0.204 · M 0.051→0.088 ·
A 0.067→0.033 · C 0.039→0.037. **열거·관계·다중 홉에서 이득, 집계(개수)·교차 조건은 이득 없음.**

## 4. 주장의 범위 — 측정하지 않은 것

- **도메인**: 한국어 위키 리드(백과체)만. 뉴스·상품·정책 문서는 미측정 — 3차 정의문 채널은 백과체 전용 처치다.
- **판독기**: 로컬 8B. 제품 합성 모델(상용 대형 LLM)에서 같은 이득이 나는지 미측정 — 큰 판독기는 그래프를 덜 필요로 할 수 있다.
- **크기**: HOLDOUT +0.057 은 기준 +0.05 를 근소하게 넘는다. 구조형 평균 0.108 은 여전히 낮다(정답 그래프 +0.630 대비 ontokit 은 1/10).
- **집계·교차 조건**은 개선 없음(그래프의 개수·교차 정밀도 부족).
- 문항은 템플릿 생성 — 자연 질의 분포와 다르다. 정답은 Wikidata 본문 근거 사실이라 정답 누락(맞는데 오답 처리) 가능성 — 사람 감사 미실시.
- 로컬 LLM 추출 그래프(h2)는 EVAL 에서 MRG +0.209 였으나 조회 −0.059 로 회귀, 홀드아웃 미측정.

## 5. 다음 과제(우선순위 제안)

1. **제품 반영**: XGEN RAG 경로에 "그래프 질의 결과 병합"(계획기 → SPARQL → 결과를 답변 후보에 합침). 현재 제품은 그래프로 청크만 더 가져온다(0906 효과 0).
2. **도메인 확장 검증**: 롯데·뉴스 문서 정답셋(사람 블라인드 표시) — 이 루프로 덮지 못한 축.
3. **판독기 민감도**: 큰 모델(DGX 35B 등)에서도 이득이 남는지.
4. **추출 품질**: 정답 그래프 대비 1/10 — 관계·타입 재현율(16.7%·11.5%)이 상한을 정한다.
