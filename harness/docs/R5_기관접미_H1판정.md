## 5. 측정하지 않은 것

- 벡터+LLM 실제 답(상한만 잼) — 실제 벡터 경로는 상한보다 낮으므로, 그래프와의 실제 격차는 위 표보다 작을 수 있다(미측정)
- 롯데 실문서 · 다른 도메인 · 응답 지연
- 관계 정밀도(정답이 위키데이터 본문근거 사실뿐이라 정밀도는 하한 추정만 가능)

## 6. 6차 공시 — 새 가설 H2 (처치 전 고정)

**H2: 같은 폐쇄 스키마(관계 12종 + 자유 타입)를 주고 로컬 LLM(ollama, 외부 API 0)으로 문서 단위 사실을 뽑아
ontokit 그래프에 합치면, 구조형에서 벡터 상한을 +0.15 이상 넘는다.**

- 근거: 병목이 추출 재현율이며(관계 16.7%), 오라클(100%)은 +0.72 를 낸다. 로컬 LLM 은 영주어·위치·국적 서술을
  규칙 없이 읽는다. "로컬 모델로 실제 빌드" 라는 원래 목표와도 일치(외부 유출 0).
- 처치: 문서마다 1회 호출, 출력 = 주제 개체의 {타입들, (관계키, 목적어)들}. 본문에 적힌 것만 내라고 지시.
  ontokit_r5 그래프와 합집합(같은 정규화 키로 병합).
- 모델 선택은 dev 에서만(qwen3:1.7b / qwen3:8b — 속도·재현율), 평가 문서에서 고르지 않는다.
- ⚠️ **오염 위험**: 위키 리드는 LLM 사전학습에 들어 있을 가능성이 높다 — LLM 이 본문이 아니라 기억으로 답할 수 있다.
  정답은 '본문 근거 사실'이라 기억 기반 출력은 대개 오답(FP)으로 잡히지만, 위키에서 얻은 수치를 롯데 문서로 일반화하지 않는다.
- 예상: 관계 재현율(eval) 16.7% → **≥ 40%**, 타입 재현율 11.5% → ≥ 30%, 구조형 **≥ 0.25**.
- 판정은 사전공시 §6 그대로(ontokit+LLM 팔 − V40 ≥ +0.15, CI 하한 > 0).
