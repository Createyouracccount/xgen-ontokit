# 베이스 스케일링 라운드 기록 (2026-07-22~24)

> 질문: **"베이스 모델 용량이 병목인가"** — small(68M) 고정은 라이선스·계보 사유였지
> 용량 검토 결과가 아니었다(0714). 이 라운드가 최초 검증. 심판 3인(렌즈A 76 / 렌즈C 68 /
> 주심 72) 전원 CONDITIONAL → 비용 상한 실측 후 **C3(기본 발효 기각) + opt-in 프로파일 배포**로 종결.

## 통제 설계
- v13c 레시피 완전 고정(train−tune 26,470 + SREDFM aug 캡8000 + 하드셋 748×1, SEED 20260714,
  마커, MAX_LEN 180, BATCH 32, ≤4에폭, hard_dev 조기종료). 재현: `scaling_train.py`(env
  SCALE_MODEL/SCALE_LR/SCALE_WARMUP/SCALE_OUT), 평가: `scaling_eval.py`.
- 움직인 변수 = 베이스 + LR(base·large 1e-5/2e-5/3e-5 스윕). warmup 0.1 추가런은 기각(0.6659<0.6724).

## 비용 게이트 (사전 선언: 빌드 +30% 초과 시 F1 무관 채택불가)
- 300기사 A/B 전체빌드(생산 경로): small 51.9s vs large fp32 123.8s = **+139%**. RE가 빌드의 79%(뉴스 코퍼스).
- 완화 전 단 실측 소진: fp16 +121%(MPS fp16 이득 −8%뿐) · 배치(ENC_BATCH_SIZE=32 기배선, 여지 없음) ·
  ONNX int8(품질 0.6740 통과·속도 13.4<17.4 rows/s 역효과, ARM ORT).
- **판정 C3**: 기본 발효 기각, v13c 유지. 단 fp16 무손실(0.6726) 실증으로 **opt-in 프로파일 배포**.

## 교훈

2. hard_dev(132행)는 근접 후보 선별자 퇴역 — holdout과 괴리 2회 실증. 조기종료용/선정용 dev 분리.
3. 사전 선언 비용 상한은 유리한 결과(+26pt)로도 면제 불가.
4. 환경 혼재(MPS/CUDA) 의혹은 교차 재평가(0.6724 정확 재현)로 소거 — 표준 절차.
